# Cryptogram Game

The purpose of this project was to follow the software development lifecycle within a team. It allowed us to explore how the software development lifecycle can be applied in a given context.

# Features

- **Dual Cipher Modes**: Supports cryptograms mapping original letters to either alternative letters or unique numeric values (without mapping letters to themselves).
- **Progress Tracking & State Persistence**: Tracks game progress, maintaining the partial state of completed and active cryptograms.
- **Player Statistics & Scoreboards**: Tracks user performance metrics and displays scores, such as the total number of successfully completed puzzles.
- **Automated Unit Testing**: Comprehensive test suites verifying domain logic against defined user story acceptance criteria.

# Tech Stack
- **Language:** Java
- **Testing:** JUnit
- **Version Control:** Git / GitLab

# How to Run

- Clone repository and open the project in IntelliJ
- Run the main method located in `Main.java`
